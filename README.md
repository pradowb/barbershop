# Navalha — Barbearia Social Club

Landing page para uma barbearia de autor em Lisboa: serviços, estúdio, planos e agendamento. Projeto de portefólio.

**Ver online:** https://barbershop-pied.vercel.app

![Página inicial da Navalha](screenshot.jpg)

## Tecnologias

- React e TypeScript
- TanStack Start com Vite
- Tailwind CSS e componentes Radix UI
- Framer Motion nas animações
- Supabase
- Publicado na Vercel

## Correr localmente

```bash
npm install
npm run dev
```
