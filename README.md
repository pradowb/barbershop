# Razor Edge Collective

Crie uma landinpage de barbearia moderno e premium inspirado em grandes empresas de tecnologia.

Objetivo:

- Visual sofisticado.

- Performance máxima.

- Motion design elegante.

- Experiência fluida.

Visual:

- use cores como, branco, preto e vermelho

- Tipografia grande.

- Grid moderno.

- Cartões com bordas suaves.

- Gradientes discretos.

- Glassmorphism apenas quando agregar.

Animações:

- Fade + translate suaves.

- Scroll reveal.

- Parallax leve.

- Hover elegante.

- Botões responsivos.

- Microinterações.

- Nada exagerado.

Performance:

- Lighthouse acima de 95.

- Lazy loading.

- Imagens otimizadas.

- CSS otimizado.

- Evitar bibliotecas pesadas.

- Respeitar prefers-reduced-motion.

Tecnologias:

- React

- Tailwind

- Framer Motion
